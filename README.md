# TVBoxOS-Mobile

一个自用的开源 Android TVBox 客户端，支持手机与平板，按自己的需求持续修改中。

## Fork 说明

- 本项目 Fork 自 [kukuqi666/TVBoxOS-Mobile](https://github.com/kukuqi666/TVBoxOS-Mobile)。
- 已脱离原仓库独立发展，**不再向上游提交 PR**，后续改动完全按本仓库自己的方向进行。
- 感谢原作者及上游所有贡献者。

## 构建

```bash
./gradlew :app:assembleDebug --stacktrace --no-daemon
```

环境要求：JDK 17、Android SDK（API 34），详见 [CLAUDE.md](CLAUDE.md)。
